# Vihaas-Web-app
A responsive, high-performance web application developed for Vihaas Design Technology using React, Tailwind CSS, and JavaScript (ES6+). This project integrates React Router for efficient client-side routing, delivering a seamless user experience. Built to showcase the company's digital presence with modern web development best practices.


# Vihaas Web App

This is the official website for **Vihaas Design Technology**, built using modern web technologies for optimal performance, responsiveness, and user experience. The project utilizes React and Tailwind CSS for a seamless front-end experience and React Router for efficient client-side routing.

## Table of Contents
- [Features](#features)
- [Tech Stack](#tech-stack)

## Features
- **Responsive Design**: Fully responsive website designed with Tailwind CSS for seamless experience across all devices.
- **Dynamic Routing**: Efficient client-side routing with React Router, enhancing performance and navigation speed.
- **Optimized Performance**: Lazy loading, optimized assets, and routing for a performance score of 99.
- **Modern UI**: Clean, modern, and interactive UI that aligns with the branding of Vihaas Design Technology.

## Tech Stack
- **Frontend**: React, JavaScript (ES6+), Tailwind CSS, React Router, HTML5, CSS3
- **Build Tools**: Webpack, Babel
- **Version Control**: Git & GitHub
